# Spring Boot 2 + Angular 13: User Registration and Login using JWT Authentication, OAuth2 Social Login with Facebook, Google, LinkedIn, and Github using Spring Security 5 and Two Factor Authentication (2FA)

## Requirements

- **Node.js 18+** ([nodejs.org](https://nodejs.org/))
- npm (comes with Node)

---

## Getting started

```bash
# 1. Install Backend dependencies
npm install

# 2. Launch Project
npm start
```
